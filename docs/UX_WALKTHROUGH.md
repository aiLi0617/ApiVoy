## 3. 目标信息架构（建议）

| 区域 | 应承载 | 现状 |
|------|--------|------|
| 资源管理器 | 工作区 / 项目 / 集合 / 请求；导入导出；集合 **运行** | 无 Run；导入仅在此 |
| 协议导航 | 仅协议工作台（API / 实时 / 消息 / 数据） | 工具 + 协作也挤在同一轨 |
| 工具 | Mock、Capture、Gateway 任务、Runner（可选面板） | 与协议同级 tab |
| 账户 / 协作 | Team、成员、同步；SSO 为登录方式；Comments 为侧栏 | 三个独立「协议」tab |
| Settings | 主题、语言、协作 URL、AI/Gateway 凭据、插件 | 仅主题/语言在顶栏 |
| 工作台工具条 | 发送、保存、Code、环境指示 | HTTP 相对完整，其余碎片化 |

### UX-001 缺少统一 Settings / 偏好面

| 字段 | 内容 |
|------|------|
| **等级** | P0 |
| **状态** | done |
| **维度** | 放置 |
| **模块** | `AppShell.tsx`、`SettingsDialog.tsx`、`userPreferences.ts`、各工作台内联配置 |

**问题**：主题与语言在顶栏；协作 URL、AI endpoint/密钥、Gateway URL/key、Agent 提示分散在各页。i18n 已有 `nav.environments` / `nav.history`，无对应壳层入口。

**理想**：独立 Settings（或 Preferences）：外观、语言、通道/Agent、协作、AI BYOK、Gateway、插件。协议导航只放协议。

**处理说明**

| 项 | 说明 |
|----|------|
| **已做** | 顶栏齿轮 + ⌘, / 命令面板打开 Settings 对话框；分区含外观、语言、Agent、协作、AI、Gateway；`userPreferences` 统一读写并派发变更；Team/SSO/Comments/AI/Gateway 消费同一源；顶栏保留主题快捷，语言迁入 Settings |
| **边界** | 插件仍在 Plugins 工作台（UX-018）；未做 `nav.environments` / `nav.history` 壳层入口；Agent URL/Token 覆盖在刷新后对客户端完全生效；密钥不进 `appStore` |
| **验证** | 改协作/AI/Gateway 偏好后对应工作台一致；协议导航无 settings tab |

**变更记录**

| 日期 | 说明 |
