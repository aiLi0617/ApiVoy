关键差异

不是谁更好，而是谁更像你的产品

Lucide

气质
理性、轻量、开发者工具
覆盖
中等偏广，常用 UI 足够
优势
风格一致，命名直观，迁移简单
限制
品牌和冷门业务图标较少

适合：IDE、API 客户端、文档工具、设置密集型产品。

Tabler

气质
几何、工程、信息密集
覆盖
四者中最广之一
优势
冷门图标容易找到，格式齐全
限制
选择过多，团队容易出现语义漂移

适合：大型后台、ERP、监控平台、跨行业 SaaS。

Heroicons

气质
现代 Web 产品、组件化
覆盖
相对精简，聚焦常用界面
优势
16/20/24 尺寸与 solid 版本明确
限制
协议、数据、工程类隐喻选择较少

适合：Tailwind 产品、营销后台、表单和 CRUD 应用。

Phosphor

气质
友好、鲜明、表现力丰富
覆盖
广，且每个图标有多种 weight
优势
regular/bold/fill/duotone 可表达状态
限制
若权重不受控，很容易混成多套风格

适合：消费产品、教育、内容工具、需要插画感的界面。

ApiVoy 落地方式

先统一规则，再替换路径

主图标系统

  • 使用 lucide-react，保留现有 <Icon name="…" /> 包装层。
  • 工具栏 16–18px，导航 18px，空状态 24px。
  • 全局固定 1.8px 或 2px 描边，只选一种。
  • 使用 currentColor，由按钮和状态组件控制颜色。

例外与边界

  • GraphQL、GitHub、Kafka 等品牌只用官方 SVG 或 Simple Icons。
  • 不要在同一区域混入 Tabler 或 Phosphor 补缺口。
  • 缺少协议图标时，优先使用语义隐喻，再绘制同网格自定义图标。
  • 字符按钮 ••• ↑ ↓ × ✓ 逐步替换为统一 SVG。
预览图标通过 Iconify API 加载，仅用于视觉比较；正式实现应安装并锁定各图标库的官方包，同时保留相应许可证声明。
